KEUANGAN USAHA

Keuangan & pengeluaran

Pengeluaran langsung mengurangi saldo sumber uang yang dipilih. Bensin, minyak tanah, dan kas tambahan ditampilkan terpisah; centang gabungan bila diperlukan.

Modal default barang

Modal per unit digunakan sebagai nilai awal ketika menambahkan stok baru. Modal batch yang sudah tercatat tidak berubah.

Catat pengeluaran

Pilih jenis pengeluaran dan sumber uang. Jika membeli bensin/minyak tanah untuk stok, tambahkan juga stok melalui Tabel Stok. Jangan mencatat pembelian yang sama dua kali: formulir ini hanya untuk pengeluaran kas yang tidak tercatat sebagai stok masuk.

Catat pergerakan kas lainnya

Untuk setoran awal, tambahan uang pemilik, atau pengambilan pribadi. Tidak termasuk pendapatan penjualan.

PREFERENSI APLIKASI

Pengaturan

Sesuaikan nama, harga, dan tampilan.

Nama & harga default

Nama digunakan sebagai pilihan saat menambah stok.

Teks halaman Home

Ubah judul dan deskripsi pada kartu utama di halaman Home.

Jenis bensin & alias

Alias untuk ukuran 20/15 dapat diganti. Tambahkan merek bensin baru seperti Pertamax; data lama tetap aman.

Ukuran / tipe eceran tambahan

Tambahkan ukuran baru selain 20 dan 15. Setiap ukuran dapat memiliki alias dan harga jual default sendiri.

Pom Mini · Harga default per liter untuk setiap jenis bensin

Harga jenis bensin menjadi default per liter di POM Mini; harga khusus bisa diisi langsung saat transaksi.

Tampilan

Tema menerapkan class .light atau .dark ke seluruh aplikasi. Aktifkan Custom untuk mengatur warna setiap bagian secara terpisah.

Otomatisasi stok

Jika aktif, catatan stok akan dipindahkan ke riwayat saat sisa stok mencapai nol. Jika nonaktif, simpan manual dengan tombol ✓ Simpan.

Cadangan data

Ekspor seluruh stok, riwayat, transaksi, pengeluaran, pergerakan kas, dan pengaturan ke file JSON. Simpan file ini di tempat aman. Impor akan mengganti data lokal yang ada.

Zona berbahaya

Menghapus semua data akan menghilangkan tabel, riwayat, nama dan pengaturan harga.
