KEUANGAN USAHA

Keuangan & pengeluaran

Arus kas terpisah dari nilai stok dan keuntungan. Saldo dan laba adalah perkiraan; stok lama tanpa modal tercatat tidak bisa dihitung akurat.

Catat pengeluaran operasional

Jangan masukkan pembelian stok di sini; pembelian stok dicatat melalui formulir Tambah Stok agar modal batch tidak dihitung dua kali.

Catat pergerakan kas lainnya

Untuk setoran awal, tambahan uang pemilik, atau pengambilan pribadi. Tidak termasuk pendapatan penjualan.

Otomatisasi stok

Jika aktif, catatan stok akan dipindahkan ke riwayat saat sisa stok mencapai nol. Jika nonaktif, simpan manual dengan tombol ✓ Simpan.

Cadangan data

Ekspor seluruh stok, riwayat, transaksi, pengeluaran, pergerakan kas, dan pengaturan ke file JSON. Simpan file ini di tempat aman. Impor akan mengganti data lokal yang ada.
